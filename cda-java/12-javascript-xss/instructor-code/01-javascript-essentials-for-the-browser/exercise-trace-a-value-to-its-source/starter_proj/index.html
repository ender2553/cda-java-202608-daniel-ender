Trace a Value to Its Source

Contained teaching page. Everything here runs locally in your browser. This page makes no network calls and does not render any value you supply. It reads values from input sources and logs them to the console only. Open your browser's DevTools console to see the output.

Try loading this page with a query string, for example index.html?name=Ada, then open the console. Type something into the field below and click the button to read a second value.

Values are logged to the console. Open DevTools to view them.
