# Java Fundamentals Coding Exercises — Student Edition

Forty CodingBat-style exercises covering arithmetic, branching, loops, strings, arrays, collections, OOP, and secure-coding scenarios.

## Requirements
- JDK 17+
- Maven 3.9+

## Workflow
1. Open `JavaFundamentals.java`.
2. Replace one `throw todo(...)` at a time.
3. Run `test` after each change.
4. Do not modify method signatures or tests.

Tests are grouped by topic, so a group may stop at its first unimplemented method. IDEs can run one test method at a time. Exercise requirements and examples are in `EXERCISES.md`.
