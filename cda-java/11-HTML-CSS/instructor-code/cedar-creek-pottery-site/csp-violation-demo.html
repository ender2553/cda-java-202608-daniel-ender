CSP violation demo

This page breaks the rules on purpose. It carries the same policy as the rest of the site, plus three things that policy refuses:

  • an inline <script> just before </body> (blocked by script-src 'self')
  • a style= attribute on the paragraph below (blocked by style-src 'self')
  • an image from another origin (blocked by img-src 'self')

If this paragraph is big and red, the policy is not enforcing.

What the browser blocked

Open the dev tools console too — it shows the same violations in red, and "inline test" never prints.

    The right fix

    Delete the inline script, move the styling into css/site.css, and serve the image from img/. Never loosen the policy to let bad practice back in.
